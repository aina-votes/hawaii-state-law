## Extracted claims

| Claim | Pin cite |
|---|---|
| A ballot package contains: official ballot, postage-prepaid return identification envelope, secrecy envelope or sleeve, instructions | §11-102(a)(1)–(4) |
| The clerk mails, non-forwardable, to each **registered** voter, targeting receipt ≥18 days before the election; State/counties not liable if later | §11-102(b) |
| The clerk continues mailing to voters registering **≤10 days** before the election | §11-102(b) |
| The clerk continues mailing to voters updating their address **≤7 days** before, **and who have not yet voted** | §11-102(b) |
| The clerk **may** continue past those deadlines if there is "reasonable time" — discretionary | §11-102(b) |
| The clerk **shall not** mail to a voter flagged with an outdated or non-deliverable address | §11-102(b) |
| Ch. 15 (absentee) and Ch. 15D (military/overseas) responsibilities are unchanged by this part | §11-102(b) |
| Envelope exterior must carry translation instructions in Hawaiian + the 5 most-used LEP languages | §11-102(c) |
| Clerks determine and provide voter service centers and places of deposit | §11-102(d), citing §11-92.1 |
| Version in force: L 2019 c 136 → am L 2021 c 213 §18 → am L 2022 c 166 §2; the 2022 amendment applies beginning with the 2024 primary | history note + L 2022 c 166 §5 |
